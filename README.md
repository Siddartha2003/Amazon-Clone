# 🛒 Amazon Clone

This is a clone of the Amazon homepage built using HTML, CSS, and JavaScript. The project is currently **under development**, with the homepage completed and more features planned.

- ✅ Responsive Amazon-like homepage layout

- ✅ Product section design with cards

- CSS3
- JavaScript
